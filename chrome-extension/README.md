# URL 복사 (트래커 제거)

내 크롬에서만 쓰는 로컬 확장. 단축키 또는 툴바 아이콘으로 현재 탭의 URL을 복사한다.

| 동작 | 결과 |
|------|------|
| **Shift + Cmd + C** (또는 툴바 아이콘 클릭) | 전체 URL 복사 |
| **Shift + Cmd + C 따닥** (0.5초 안에 두 번) | 트래커 파라미터(`utm_*`, `gclid`, `fbclid` 등) 제거 후 복사 |

> **원리**: 첫 번째 누름에 전체 URL을 복사하고, 두 번째 누름이 클립보드를 트래커 제거 버전으로 덮어쓴다. 복사될 때마다 화면 우상단에 토스트로 알려준다(파란색=전체 / 초록색=트래커 제거). 툴바 아이콘 클릭도 동일하게 동작하며, 단축키가 다른 앱/단축키와 충돌할 때의 폴백이 된다.

## 설치

1. 크롬에서 `chrome://extensions` 접속
2. 우상단 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램을 로드합니다** 클릭 → 이 폴더 선택
   `/Users/jisungbin/IdeaProjects/copy-url-kt/chrome-extension`
4. `chrome://extensions/shortcuts` 에서 단축키가 **Shift+Cmd+C**로 잡혔는지 확인

## 알아둘 점

- **단축키가 안 먹으면** 크롬 기본 단축키(개발자도구 요소검사 등)와 충돌했을 가능성이 높다.
  `chrome://extensions/shortcuts` 에서 이 확장의 입력란을 클릭해 **직접 Shift+Cmd+C를 눌러 지정**하면 확장이 우선권을 가져온다. 그래도 불안하면 툴바 아이콘 클릭으로 쓰면 된다.
- `chrome://`, 크롬 웹스토어 페이지에서는 브라우저 정책상 작동하지 않는다(일반 웹페이지에서만 동작).
- 따닥 인식 간격은 `background.js`의 `DOUBLE_TAP_MS`(기본 500ms).

## 트래커 목록 수정

`background.js` 상단의 `TRACKER_EXACT`(정확히 일치) / `TRACKER_PREFIXES`(접두사 일치)를 편집하고, `chrome://extensions`에서 이 확장의 **새로고침(↻)** 버튼을 누르면 반영된다.

특정 사이트에서 필요한 파라미터까지 지워진다면, 그 경우엔 따닥 대신 한 번만 눌러 전체 URL을 쓰면 된다.
(예: 유튜브 공유 링크의 `si=`는 이름이 너무 흔해 기본 목록에서 제외했다. 필요하면 `TRACKER_EXACT`에 `'si'` 추가.)

## 아이콘 다시 만들기

아이콘은 `gen_icons.py`로 생성한다(`PIL` 필요). 디자인을 바꾸려면 스크립트를 수정하고:

```bash
python3 gen_icons.py
```

`icons/icon{16,32,48,128}.png` 가 갱신된다.
